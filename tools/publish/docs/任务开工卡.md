# 视频任务开工卡（每次直接复制给执行模型）

> 用途：视频剪辑、字幕、封面、上传、修改、删除。默认 dry-run，未验收不得发布。

做视频/封面/发布任务时，先不要上传、删除、覆盖任何线上内容。

1. 先读取：
   - `tools/publish/封面规范.md`
   - `tools/publish/字幕规范.md`
   - `tools/publish/发布流程坑位清单.md`
   - 本任务的 `manifest.json`（没有就先创建）
2. 若文档与代码/最终成品冲突，先列冲突并停止，不得自行选择旧规则。
3. 先给：目标平台、目标作品 ID、版本号、输入文件 hash、封面比例、字幕规范、验收截图计划。
4. 默认只 dry-run；任何发布/删除/覆盖都必须我单独确认。
5. 每次点击后必须做对象级断言：不是“clicked”，而是目标状态已改变。
6. 上传必须等真实完成信号；禁止固定 sleep 后直接发布。
7. 发布完成必须回列表，核对：标题、时长、封面、可见范围，并截图。
8. 任一步失败：立即停止同类操作，写失败记录，给修复方案；不得连续盲试。
9. 成片交付前必须给：首帧、3:4/16:9 裁切模拟、亮背景字幕帧、音画同步检查点。
10. 报告里明确区分：已验证事实 / 推断 / 未知。

## 开工先定三件事（2026-11-06）

1. 成片形态：精选 / 完整；哪些平台发哪一种。
2. 平台与旧稿：是否替换、是否允许删除；删除必须用户点名。
3. 封面：每个比例独立排版，主标题 ≥96px（16:9 ≥120px），辅助字 ≥64px（16:9 ≥72px）；缩到 360px 宽验收。

## 验收通过才允许发布

- [ ] 首帧 = 设计封面
- [ ] 3:4 与 16:9 裁切模拟均不裁字、不切脸
- [ ] 字幕字号、断行、时间轴、亮背景可读性通过
- [ ] 开头/中段/结尾音画同步
- [ ] 上传真实完成，字段与 manifest 一致
- [ ] 回列表截图，标题/时长/封面/可见范围正确
- [ ] 平台实际缩略图已截图：人脸比例正常、标题可读、无竖卡套横版/黑边
- [ ] 无重复、无误删、无未说明变更
